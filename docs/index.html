⚡ Git-Backed Shared Memory for AI Agent Fleets

The shared memory your AI agent fleet keeps forgetting it needs.

KYB is a high-speed BM25 hybrid search engine and incident tracker written in Rust. It preserves operational truth, host maps, topology, and post-mortems across AI agent sessions.

Deploy in 60 Seconds Explore GitHub Repo
bash — kyb query, incidents & tasks
agent@fleet:~$ kyb query "which servers run clickhouse?"
✓ Match 1 (score 0.867): orders-api-architecture "orders_api on host-a is the single write path into ClickHouse (gRPC :9000)" ✓ Match 2 (score 0.836): host-a-services "host-a runs orders_api and web_app next to the local ClickHouse container"

agent@fleet:~$ kyb incident --key inc-2026-08-06-orders-api-oom --severity critical

Built for Autonomous Agent Operations

Prevent hallucinated infrastructure topologies and lost incident history.

⚡

Hybrid BM25 Search (~6ms)

Sub-10ms lexical and semantic search over inverted indices. Agents get exact hostnames, ports, and configuration anchors instantly.

📜

Git-Backed Version History

Every knowledge addition, incident, and resolution is backed by Git commits. Complete audit trail of system decisions across sessions.

🛡️

Zero Secret Leak Guard

Automatic regex credential scanner blocks passwords, API tokens, and SSH keys from entering the knowledge base. Only safe pointers allowed.

🤖

Multi-Agent Skill Injector

One-line installer configures skills and system prompt rules across Claude Code, Codex CLI, and Antigravity (AGY) automatically.

🚨

Structured Incident Tracking

Mandatory resolution workflows. Require agents to record symptoms, root causes, workarounds, and resolution proofs before closing incidents.

✅

Task Board for Agents

Short actionable notes with an optional priority (low → critical) and a real lifecycle: open, in_progress, blocked (with the reason it waits on), done, dropped. Only done and dropped close and archive — everything still in flight stays listed and counted.

🐳

Zero-Dependency Docker Deploy

Packaged into a lightweight Docker image ready to deploy on any server in seconds with persistent JSON/Markdown storage.

Quickstart in 60 Seconds

Run the server and equip your agent fleet.

1. Start the KYB Docker Server:

docker run -d --name kyb -p 9310:9310 -v "$PWD/data:/data" --restart always ghcr.io/alex09x/kyb:latest

2. Inject KYB Skill into Agent Fleet (Claude Code, Codex, Antigravity):

KYB_SERVER=your-server-ip ./skills/install.sh
